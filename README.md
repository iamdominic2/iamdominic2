### Hello!
I am a passionate Scratch programmer. Solo dev who works on interesting projects in his free time. In recent years, I have decided to make high-quality games (compared to before, when I valued quantity over quality - but then I realized nobody would play them!)

Here is my workflow:<br>
I would make a game incrementally in Scratch, and then package it in TurboWarp to reduce lag, increase loading speeds, have high-quality pen, e.t.c. Over the course of days or weeks, something interesting would come out.

My repos' structure contains:<BR>
`assets`: Which assets have what names and belong to which sprites.<BR>
`media`: The unzipped `.sb3` file<BR>
`scripts`: The Scratch blocks, variables, and lists before I packaged it into a single `.html` file.<BR>
`PROJECTNAME.sb3`: The Scratch 3 file.<BR>
`README.md`: What you see on the main page! It will contain the GitHub Pages link to play the game immediately, and also a Scratch link to show that it is possible in Scratch (which, after all, is still Turing-capable)<BR>
`index.html`: The file actually needed to run the link immediately in your browser.

#### Have fun!
